# Wine Quality Testing

Machine Learning project for analyzing and predicting wine quality using physicochemical attributes.

## Algorithms
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest

## Evaluation
Models are evaluated using accuracy score, confusion matrix, precision, recall and F1-score.

## Project Structure
- `data/` - dataset files
- `notebooks/` - exploratory analysis and experiments
- `src/` - preprocessing, training and evaluation code
